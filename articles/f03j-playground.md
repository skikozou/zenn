# 3. F-03J とは

F-03J は2017年3月に発売されたdocomoのキッズケータイで、キッズケータイシリーズとして初めてAndroidを搭載した機種です。

子供向けの連絡用デバイスとして発売されていました。

キッズケータイシリーズとしては約2年4ヶ月ぶり、富士通製のキッズケータイとしては2009年以来約8年ぶりの新機種でした。

後継機種には SH-03M があり、タッチパネルを搭載するなど、F-03J より機能面で充実しています。
ソフトウェアアップデートは終了しており、2026年の3G停波以降は電話・メールとしての利用もできません。

このような経緯もあり、改造する対象としての注目度は低く、今まで目立った改造はありません。

今回はこのデバイスでroot取得や各種機能の操作について扱っていこうと思います。

# 4. 遊び方

## 4-1. セットアップ

### ホスト環境を用意する

USB ポートのあるデバイスと、そのデバイス内で USB を扱える環境を用意します。
Linux がオススメですが、Android でも可能です。

この環境を以降ホストと呼びます。要件と導入手順はリポジトリを参照してください。

リポジトリ：(リポジトリURL)

### USB ケーブルを用意する

データ通信ができる Micro-B のケーブルであれば何でも構いません。ホスト側の形状に合うものを選んでください。

基本的には A to Micro-B で十分でしょう。

### ADB を確立する

開発者向けオプションを有効にし、USB デバッグを ON にします。手順は次のとおりです。

1. ホーム画面で「メニュー」→「設定」→「安心セット」を開く
2. パスワードを入力する
購入時の初期値は「0000」
3. 「その他」→「高度な設定」→「端末情報」を開く
4. 「ビルド番号」を連打する
5. 「高度な設定」に戻り、「開発者向けオプション」を開く
6. 開発者向けオプションを ON にし、「USB デバッグ」を ON にする
7. USB ケーブルでホストと接続する

ホスト側から端末が見えることを確認してください。

### root を取得する

初回だけ exploit を実行して root を取得し、そのあと永続化します。
永続化以降は、再起動しても exploit を走らせる必要はありません。

初回の実行は起動から 5 分ほど待機してから行ってください。
取得と永続化の具体的な手順はリポジトリを参照してください。

exploitは不安定なのでデバイスが再起動、ハングする場合があります。
ハングした場合は強制再起動をしてください。
1 キーと電源ボタンを同時に32秒間長押しすると強制再起動します。

## 4-2. 使い方

### Root shell

`rootsu` に接続すると、uid=0 のシェルが起動します。
adb からでも、端末上のTermuxからでも入れます。

シェルでは通常のコマンドがそのまま動きます。
ただし `/system` への書き込みだけは fjsec によって拒否されるので、その場合は後述の fjsec 無効化を先に行ってください。

### カーネルでの ACE

カーネルの任意アドレスを読み書きできます。
アドレスを指定して読み書きするだけで、exploit を毎回走らせる必要はありません。

初回だけ、起動時に自己参照化を済ませておく必要があります。
起動時の自動化を有効にしていれば、待つだけで終わっています。

読み書きできる長さには上限があります。
読み取り専用の領域へ書き込むと、失敗してエラーが返ります。

### スクリーンミラー

F-03J の画面をホストに表示し、ホスト側から物理キーを操作できます。
タッチスクリーンがない端末なので、操作はすべてこの経路か実機のキーになります。

表示環境がホストに必要です。
起動用のスクリプトを走らせると、adb 経由で画面が流れます。

更新頻度と画質は環境変数で調整できます。
電池とホストの負荷を見ながら決めてください。

（このプログラムはtermux x11用なのでいつか書き直す）

### Bluetooth 経由の操作

USB を繋がずに、SPP 経由でシェルを操作できます。

ホスト側に SPP サーバーを立てられるアプリが必要です。

初回のペアリングだけは実機の UI から行います。

### fjsec を無効化する

`/system` を読み書きする場合だけ必要になります。

専用のバイナリを実行し、再マウントするだけです。
ただしこの状態は再起動で失われるので、`/system` を触るたびにやり直すことになります。

### インターネットに接続する

USB 経由で、ホストの回線を F-03J に提供できます。

ホスト側に gnirehtet を用意し、端末側で VPN 権限を許可します。
あとは開始用のスクリプトを走らせるだけです。

経路は USB ADB です。Bluetooth 経由ではない点に注意してください。
